# coolstuff notation

One notation across the whole site, so a symbol means the same thing in
calculus, linear algebra, ML and physics. The macros live in
[`notation.ts`](./notation.ts) (`TEX_MACROS`) and are loaded into every KaTeX
render (Formula, Derivation, WorkedExample, Problem, build-time prerender).
`notation.test.ts` renders every macro below and fails if one is missing from
this file.

Rules of thumb:

- **All maths goes through KaTeX**, including a single Greek letter in a
  sentence. Never fake maths with Unicode italics or bare Greek in prose.
- **Write the meaning, not the look.** Use `\vec{v}`, not `\mathbf{v}`;
  `\colorTerm{output}{y}`, not `\color{orange}{y}`. Then a site-wide change is a
  one-line change.
- **No inline colours in TeX, ever.** Colour comes from concept classes
  (`\colorTerm`), so terms re-theme instantly between light, dark and print.

---

## 1. Colour, annotation, change

| Macro | Expands to | Use |
|---|---|---|
| `\colorTerm{name}{tex}` | `\htmlClass{ct ct-name}{tex}` | Colour a term by **concept** (`input`, `output`, `error`, `prob`, or a lesson concept from `defineConcepts`). Hovering it lights the same concept in the figure and prose. |
| `\ct{name}{tex}` | same | Short alias for `\colorTerm`. |
| `\c<Name>` | `\colorTerm{name}{symbol}` | Per-lesson shorthands generated by `defineConcepts(...).macros()` from each concept's `symbol`, e.g. `\cMatrix` → coloured *A*. Pass them to `Formula` as `macros`. |
| `\anchor{id}{tex}` | `\htmlData{anchor=id}{tex}` | Tag a term so explain-this notes and live values can find and point at it. |
| `\chg{tex}` | `\htmlClass{chg}{tex}` | The highlighter: marks what changed in a derivation step. Not a concept. |

`correct` is a global state class too (`\colorTerm{correct}{…}` for a boxed
result), but no lesson concept may be green.

## 3. Calculus

| Thing | Write | Notes |
|---|---|---|
| differential d | `\d x` | upright d, thin space before it in integrals: `\int_a^b f(x)\,\d x` |
| Leibniz derivative | `\dv{y}{x}` | rates, the chain rule, related rates, separation of variables, physics |
| Lagrange derivative | `f'(x)`, `f''(x)` | default in Calculus I once the derivative is defined |
| Newton (time) derivative | `\dot x`, `\ddot x` | time derivatives in physics and ODEs only |
| partial derivative | `\pdv{f}{x}` | `f_x` only in Calculus III after it is introduced, when space is tight |
| gradient | `\grad f` | ∇*f*; `\grad_{\bm\theta} \loss` in ML |
| divergence, curl | `\divg \vec F`, `\curl \vec F` | ∇·**F**, ∇×**F** |
| evaluation bar | `\eval{F(x)}_{a}^{b}` | |
| limit | `\lim_{h \to 0}` | |
| sum | `\sum_{i=1}^{n}` | 1-based in maths unless the lesson says otherwise |

**Which derivative notation, when:** introduce the derivative with Leibniz
(`dy/dx` reads as "a small change in *y* per small change in *x*", which the
secant picture shows), switch to Lagrange for rules and computation, use
Leibniz again wherever units or the chain rule matter, and dots only for time.

## 7. Physics, units and numbers

| Thing | Write | Notes |
|---|---|---|
| vector quantity | `\vec F`, `\vec v`, `\vec E` | magnitude italic: `F = \abs{\vec F}` |
| quantity with unit | `\unit{9.8}{m/s^2}` | number, thin space, upright unit: 9.8 m/s². Products `\unit{12}{N\cdot m}` |
| gravity | `g = \unit{9.8}{m/s^2}` | say "take *g* = 9.8 m/s²" in the problem |
| angles | radians in formulas; degrees with ° in prose and figures | |

**Numbers in prose, readouts and figures**

- Decimal point `.`; thousands with commas (`12,500`); a narrow no-break space
  (U+202F) between a number and its unit in prose: `9.8 m/s²`.
- The minus sign is U+2212 `−`, never a hyphen, in prose, readouts and figure
  ticks (`formatNumber` in the kit does this).
- Multiplication in prose is `×` (`stretched ×3`); scientific notation
  `3.0 \times 10^{8}`.
- **Precision:** final answers to 3 significant figures unless exact; exact
  values stay exact (`\tfrac{1}{3}`, `\sqrt 2`). Live readouts use a fixed 2
  decimals with tabular figures so they don't jitter; angles 1 decimal plus °.
  Probabilities as decimals in maths (`0.25`), percentages allowed in prose.
- Numeric answers state their precision ("to 2 decimal places") and accept
  ±0.5 in the last stated digit; physics answers also check the unit.

## 8. Multi-line maths: relation chains

Worked-example steps and solutions are rendered by `mathChainHtml()`. It
splits a step at its top-level relations; on a wide screen the step is one
line, and on a phone each "relation + right-hand side" wraps as a unit and
lines up under the first relation:

```
det(B − λI) = (4 − λ)(3 − λ) − 2
            = λ² − 7λ + 10
```

A line never ends in `=` or `⟹`, and no `0` is ever left alone. Authoring rules:

- One chain per step: `lhs = a = b = c`.
- `\implies` / `\iff` start a new clause (a consequence gets its own line when space is short).
- List items are separated by `,\ ` or `\quad`: `\lambda_1 = 5,\ \lambda_2 = 2`.
- Braces protect a group from splitting: `{x = 1}`.
- Display formulas that cannot break (a big matrix) scroll inside their own
  box, never the page.

Derivations (`Derivation`) set the relation (⟺, ⟹, =) in its own gutter
column and a one-line justification beside it (below it on phones).
